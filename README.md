# thermere.github.io

The Thermere LLC website, served by GitHub Pages.

## Structure

- `index.html` — the Thermere home page and the road ahead.
- `malimar-network/` — the Malimar Network section, with the app embedded.
- `malimar-network/ballroom/index.html` — Malimar Ballroom itself, copied from the [malimar-ballroom repository](https://github.com/thermere/malimar-ballroom). That repo is where the app is developed; update the copy here when it releases.

## Publishing

GitHub Pages serves a user site from a repository named exactly `thermere.github.io`. Push this folder as that repository, and the site appears at https://thermere.github.io/ shortly after.

No build step. Plain HTML and CSS, same philosophy as the app: anyone can read everything the site does.
